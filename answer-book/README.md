# 答案之书 · Book of Answers

基于 Flask + Python requests 的本地趣味问答网页程序。在心中默念你的问题，翻开「答案之书」，获取一段神秘的答案。通过调用 [uapis](https://uapis.cn) 答案之书 API（POST 方式）实现，以网页形式呈现，并支持历史记录与翻书等待动画。

## 功能特性

- **网页形式呈现**：本地启动后在浏览器中使用，星空夜色主题界面，神秘氛围感
- **POST 请求调用 API**：后端使用 `requests` 库以 POST 方式调用答案之书 API
- **漂亮界面**：ASCII 艺术标题 + emoji 装饰（📖 🔮 ✨ 🌙），渐变文字与发光效果
- **等待动画**：提问后展示「翻书中」3D 翻书动画 + 动态省略号，提升仪式感
- **历史记录**：自动保存每次问答（最多 50 条），存储于浏览器 localStorage，刷新不丢失
- **清空记录**：一键清空全部历史记录
- **回车快捷提问**：输入问题后按回车即可翻开答案
- **异常处理**：对网络错误、超时、服务异常、空问题等情况进行友好提示

## 技术栈

- **后端**：Python + Flask（Web 框架）
- **HTTP 客户端**：requests 库（以 POST 调用答案之书 API）
- **前端**：原生 HTML / CSS / JavaScript（无额外构建依赖）

## API 说明

### 上游答案之书 API

- **接口地址**：`https://uapis.cn/api/v1/answerbook/ask`
- **请求方式**：POST
- **请求参数**：`question`（问题内容，表单字段）
- **返回格式**：`application/json`，包含 `question` 与 `answer` 字段
- **官方文档**：https://uapis.cn/docs/api-reference/post-answerbook-ask

### 本地后端接口

| 路径 | 方法 | 参数 | 说明 |
|------|------|------|------|
| `/` | GET | 无 | 渲染问答首页 |
| `/api/ask` | POST | `question`（表单字段） | 转发问题至答案之书 API，返回 JSON `{question, answer}` |

## 安装与运行

### 1. 安装依赖

在项目目录下执行：

```bash
pip install -r requirements.txt
```

### 2. 启动程序

```bash
python app.py
```

### 3. 访问页面

启动后在浏览器打开：http://127.0.0.1:5001

在输入框中输入你心中的问题（例如「我会成功吗？」「该不该换工作？」），点击「🔮 翻开答案」或按回车键，等待翻书动画结束后即可看到神秘答案。每次问答会自动保存到下方的历史记录中。

## 异常处理说明

程序对以下异常情况进行了处理并给出友好提示：

| 异常场景 | 处理方式 |
|----------|----------|
| 未输入问题 | 提示「请先输入你的问题」 |
| 请求超时 | 提示「询问超时，请稍后重试」 |
| 网络连接失败 | 提示「网络连接失败，请检查网络后重试」 |
| 上游服务异常 | 提示 HTTP 状态码及服务异常信息 |
| 返回数据格式错误 | 提示「答案之书返回数据格式错误」 |
| 未返回答案字段 | 提示「答案之书未给出答案，请稍后重试」 |
