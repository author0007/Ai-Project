# 天气查询程序

基于 Flask + Python requests 的本地天气查询网页程序。通过调用 [uapis](https://uapis.cn) 天气查询 API，输入城市名称即可获取实时天气信息，以网页形式呈现，并支持连续查询多个城市。

## 功能特性

- **网页形式呈现**：本地启动后在浏览器中使用，界面美观、响应式布局
- **连续查询多个城市**：每次查询结果以卡片形式累积展示，方便对比不同城市天气
- **格式化输出**：温度、湿度、天气状况、风向、风力、体感温度等信息结构化展示
- **气象预警**：自动展示城市当前的气象预警信息（如高温、暴雨等预警）
- **异常处理**：对网络错误、城市不存在、超时、服务异常等情况进行友好提示
- **回车快捷查询**：输入城市名后按回车即可查询

## 技术栈

- **后端**：Python + Flask（Web 框架）
- **HTTP 客户端**：requests 库（调用天气 API）
- **前端**：原生 HTML / CSS / JavaScript（无额外构建依赖）

## API 说明

### 上游天气 API

- **接口地址**：`https://uapis.cn/api/v1/misc/weather`
- **请求方式**：GET
- **请求参数**：`city`（城市名称）
- **官方文档**：https://uapis.cn/docs/api-reference/get-misc-weather

### 本地后端接口

| 路径 | 方法 | 参数 | 说明 |
|------|------|------|------|
| `/` | GET | 无 | 渲染查询首页 |
| `/api/weather` | GET | `city` | 查询指定城市天气，返回 JSON |

## 安装与运行

### 1. 安装依赖

在项目目录下执行：

```bash
pip install -r requirements.txt
```

### 2. 启动程序

```bash
python app.py
```

### 3. 访问页面

启动后在浏览器打开：http://127.0.0.1:5000

在输入框中输入城市名称（如「北京」「上海」「广州」），点击「查询」或按回车键即可查看天气。可连续输入多个城市，结果会以卡片形式依次展示。点击「清空」可清除所有查询记录。

## 异常处理说明

程序对以下异常情况进行了处理并给出友好提示：

| 异常场景 | 处理方式 |
|----------|----------|
| 未输入城市名 | 提示「请输入城市名称」 |
| 城市不存在（上游 404） | 提示「未找到城市 XXX，请确认城市名称」 |
| 请求超时 | 提示「查询超时，请稍后重试」 |
| 网络连接失败 | 提示「网络连接失败，请检查网络后重试」 |
| 上游服务异常 | 提示 HTTP 状态码及服务异常信息 |
| 返回数据格式错误 | 提示「天气服务返回数据格式错误」 |
