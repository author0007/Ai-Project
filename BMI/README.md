# BMI 计算器

一个基于 Python + Flask 的网页版 BMI（身体质量指数）计算器，在本地运行，支持输入身高体重计算 BMI 值并给出健康建议。

## 功能特性

- 输入身高（cm）和体重（kg）计算 BMI 值
- 根据 BMI 值给出健康分类和建议：
  - **偏瘦**：BMI < 18.5
  - **正常**：18.5 ≤ BMI < 24
  - **偏胖**：24 ≤ BMI < 28
  - **肥胖**：BMI ≥ 28
- 支持多次计算，并记录最近 10 次计算历史
- 美观的响应式界面，适配手机和电脑
- 输入合法性校验，防止异常输入

## 技术栈

- **后端**：Python 3.x + Flask
- **前端**：HTML + CSS + JavaScript（原生，无第三方依赖）

## 使用方法

1. 在"身高"输入框中输入身高（单位：cm，范围 50-250）
2. 在"体重"输入框中输入体重（单位：kg，范围 10-500）
3. 点击"计算 BMI"按钮
4. 查看计算结果：
   - BMI 数值
   - 健康分类（偏瘦/正常/偏胖/肥胖）
   - 对应的健康建议
5. 页面底部会显示最近 10 次的计算历史记录
6. 点击"重置"按钮可清空输入和结果

## BMI 计算公式

```
BMI = 体重(kg) / 身高²(m²)
```

例如：身高 170cm，体重 65kg

```
BMI = 65 / (1.70 × 1.70) = 22.5
```

## API 接口

应用提供以下 API 接口：

### POST /api/calculate

计算 BMI 值。

**请求参数**（JSON 格式）：

```json
{
    "height": 170,
    "weight": 65
}
```

**响应示例**：

```json
{
    "bmi": 22.5,
    "category": "正常",
    "advice": {
        "status": "体重正常",
        "color": "#27ae60",
        "tips": [
            "恭喜！您的体重在健康范围内",
            "继续保持均衡的饮食习惯",
            "坚持适量运动，每周至少150分钟有氧运动",
            "定期检查身体指标，保持健康生活方式",
            "注意作息规律，避免熬夜"
        ]
    }
}
```

**错误响应**：

```json
{
    "error": "身高和体重必须大于0"
}
```

## 注意事项

- 本应用仅供健康参考，不作为医学诊断依据
- BMI 仅是评估体重的指标之一，不能完全反映身体健康状况
- 如需专业健康建议，请咨询医生或营养师
- 应用默认在本地 5000 端口运行，如端口被占用请修改 [app.py](file:///f:/ai/BMI/app.py) 中的端口号
